# PDF Merge Pro

PDF Merge Pro is a FastAPI-based web application that allows users to upload and merge multiple PDF files into a single document through a clean and modern interface.

---

## Features

- Upload multiple PDF files
- Merge PDFs instantly
- Modern responsive frontend
- FastAPI backend
- Secure local file processing
- Simple and lightweight design

---

## Tech Stack

### Backend
- FastAPI
- PyPDF

### Frontend
- HTML
- CSS
- JavaScript
